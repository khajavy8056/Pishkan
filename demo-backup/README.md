# بکاپ نمایشی «دو ماه فعالیت دفتر»

این پوشه یک نسخه پشتیبان **کاملاً ساختگی** از پایگاه داده پیشخوان است که طوری ساخته شده
انگار دفتر حدود دو ماه است با سامانه کار می‌کند: مشتری، پرونده، پرداخت، حقوق، پورسانت،
برداشت، شیفت و حضوروغیاب، تیکت و پیام، وبلاگ و اعلان — همه با تاریخ‌های واقعیِ پخش‌شده
در دو ماه گذشته. هیچ داده واقعی در آن نیست.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `pishkan-demo-60-days.sqlite` | فایل اصلی ریکاوری (پایگاه داده کامل، ۲۷ مهاجرت) |
| `pishkan-demo-60-days-uploads.tar.gz` | پوشه فایل‌های آپلودی دمو (عمداً خالی است؛ دمو فایل باینری ندارد) |
| `pishkan-demo-60-days-summary.json` | خلاصه محتوا، شمارش‌ها، کنترل‌های سلامت و رمزهای ورود |
| `SHA256SUMS.txt` | اثر انگشت فایل‌ها برای اطمینان از سالم‌رسیدن دانلود |

## ریکاوری روی نسخه ویندوزی (روش اصلی)

1. برنامه **Pishkan Manager** را باز کنید.
2. دکمه **«بازیابی»** را بزنید و فایل `pishkan-demo-60-days.sqlite` را انتخاب کنید.
3. مدیر برنامه خودش یک کپی امن از دیتابیس فعلی نگه می‌دارد، دیتابیس دمو را جایگزین
   می‌کند و اگر سرویس روشن باشد آن را ری‌استارت می‌کند.
4. مرورگر را باز کنید و با رمزهای پایین وارد شوید.

> نکته: پنل وب (بخش عملیات) برای بکاپ‌هایی است که خود سامانه گرفته و فایل خارجی قبول
> نمی‌کند؛ برای این دمو حتماً از Manager استفاده کنید. این مسیر دقیقاً تست شده است
> (ریکاوری + بوت + ۲۹ بررسی خودکار روی دیتابیس بازیابی‌شده).

## رمزهای ورود دمو

**در ورود همکاران (`/login-admin`):**

| نام کاربری | رمز | نقش / نوع همکاری |
|---|---|---|
| `admin` | `Admin@12345` | مدیر اصلی |
| `manager` | `Demo@12345` | مدیر دفتر (ثابت) |
| `accounting` | `Demo@12345` | حسابدار (ثابت) |
| `content` | `Demo@12345` | مدیر محتوا / وبلاگ (ثابت) |
| `fixed1` تا `fixed4` | `Demo@12345` | کارمند حقوق‌ثابت |
| `percent1` تا `percent4` | `Demo@12345` | کارشناس درصدی (پورسانتی) |

**در ورود مشتری‌ها (صفحه ورود عمومی):** شماره موبایل مشتری + رمز `Demo@12345`
نمونه: `09122100000` (رضا محمودی — ۶ پرونده و موجودی کیف پول دارد).

## داخل دمو چه می‌بینید؟

- **۳۶ مشتری** ساختگی (هرکدام ۱ تا ۶ پرونده) و **۱۲ همکار** با سابقه کاری متفاوت.
- **۱۱۵ پرونده**: ۵۲ تحویل‌شده، ۱۶ در حال انجام، ۸ تازه‌ارجاع‌شده، ۶ منتظر مشتری،
  ۵ لغوشده، ۲ ردشده و **۲۶ پرونده آزادِ بدون مجری** در صف آزاد برای انتخاب کارشناس‌ها.
- **مالی واقعی‌نما**: ۱۲۹ فاکتور، ۹۸ پرداخت تأییدشده (۴۷۳٬۷۳۷٬۰۰۰ ریال)، صورتحساب‌های
  هزینه سازمانی جدا، تخفیف، کیف پول مشتری و یک پرداخت برگشتی.
- **حقوق و پورسانت**: ۱۴ پرداخت حقوق (۴۲۳٬۰۰۰٬۰۰۰ ریال؛ یک نفر بخشی از حقوق مهرش مانده)،
  ۴۱ رکورد پورسانت قطعی (۱۸٬۵۵۸٬۹۰۰ ریال) برای چهار کارشناس درصدی، و ۶ درخواست برداشت
  در همه وضعیت‌ها (ثبت‌شده، در بررسی، تأییدشده، ردشده با دلیل، پرداخت‌شده با رسید).
- **عملیات روزمره**: ۵۶۱ شیفت و ۴۲۲ رکورد حضوروغیاب، ۱۲ تیکت پشتیبانی، ۷ گفت‌وگوی پیام،
  ۱۰ هزینه دفتر، ۷ مطلب وبلاگ (۵ منتشرشده + زمان‌بندی + پیش‌نویس) و ۱٬۸۱۲ اعلان.
- رفتارهای کلیدی سر جایش است: کارمند ثابت هیچ‌جا عدد پورسانت/برداشت نمی‌بیند؛ کارشناس
  درصدی روی هر کارتِ صف آزاد سهم خودش را می‌بیند؛ درِ ورود مشتری و همکار جداست.

## چند نکته برای ارائه

- **پرداخت آزمایشی (Sandbox) فعال است** تا در جلسه بتوانید پرداخت را زنده نشان دهید.
- **تخصیص خودکار خاموش است** تا صف آزاد همیشه پر بماند و انتخاب پرونده را نشان دهید؛
  از تنظیمات نیروی انسانی می‌توانید روشنش کنید.
- تاریخ‌ها نسبت به **زمان ساخت بکاپ** چیده شده‌اند؛ اگر هفته‌ها بعد ریکاوری کنید،
  داده‌ها کمی قدیمی‌تر دیده می‌شوند. برای تازه‌کردن، اسکریپت سازنده را دوباره اجرا کنید:
  `npm run build --workspace apps/api` سپس
  `node --experimental-sqlite scripts/generate-demo-backup.mjs`
- دمو **فایل آپلودی ندارد** (عمدی است تا ریکاوری تک‌فایلیِ Manager همیشه سالم بماند).
