# گزارش اولیهٔ ممیزی — مأموریت آماده‌سازی عملیاتی «تک پیشخوان»

تاریخ: ۲۰۲۶-۱۱-۲۶ · شاخه: `arena/fe627e67-pishkan` · مبنا: `main@ec34330` · نسخه: `1.0.1218`

## ۱. ساختار و تکنولوژی واقعی

| جزء | تکنولوژی | وضعیت |
| --- | --- | --- |
| بک‌اند | Express 5 + TypeScript، Node ≥ 22.22.2 | ۲۸ ماژول دامنه، ۲۹ روتر، RBAC ریزدانه |
| وب | React 19 + Vite 7 + Tailwind 4، PWA | ~۷۰ مسیر، RTL فارسی، تم روشن/تیره با دروازهٔ کنتراست |
| اندروید | Flutter (اپ مشتری) `1.0.1218+1218` | اتصال فعلی: IP/Port دستی یا QR؛ `--dart-define` از قبل پشتیبانی می‌شود |
| دیتابیس | PostgreSQL (تولید) / SQLite (توسعه/تست) | ۴۴ مهاجرت افزایشی با checksum |
| نصب ویندوز | نصب‌کننده/مدیر گرافیکی، SQLite لوکال، LAN opt-in | selftest ۳۶ سنجه |
| نصب سرور | `scripts/install.sh` (Ubuntu 22.04/24.04) + CLI `pishkan` | idempotent، deploy.conf، certbot، systemd، nginx |

**نکتهٔ مهم دربارهٔ بند ۶.۱ دستور مأموریت:** پروژه PHP ندارد؛ پشتهٔ واقعی Node.js + PostgreSQL است.
بنابراین «بررسی نسخه PHP/افزونه‌ها» به «بررسی Node.js/ماژول‌ها/نسخهٔ PostgreSQL» نگاشت می‌شود و
نصب روی هاست اشتراکی PHP ممکن نیست. کاربر VPS با root را تأیید کرده است.

## ۲. تصمیم‌های کاربر (ثبت‌شده)

1. زیرساخت هدف: **VPS/سرور اختصاصی با root**.
2. اندروید: **فعلاً تغییری اعمال نشود**؛ پس از نصب کامل سرور، اطلاعات اتصال از کاربر گرفته
   می‌شود و آن‌گاه اتصال دائمی HTTPS پیاده می‌شود. نصب‌کننده باید «بستهٔ اطلاعات اتصال اندروید» تولید کند.
3. صفحهٔ IP/Port در بیلد نهایی حذف و فقط در بیلد توسعه بماند (اعمال در مرحلهٔ بعد، با دامنهٔ واقعی).

## ۴. شواهد آزمون واقعی (پیش از اصلاحات)

- SQLite: `npm run verify` کامل سبز (typecheck، API، وب ۱۳۴ تست، کنتراست).
- **PostgreSQL 16.2 واقعی** (pgserver): ۴۵۲/۴۶۶ پاس، ۸ شکست در ۳ فایل → ریشه‌یابی:
  F4 (سه شکست `rowid`) و F3 (پنج شکست نبودن `pg_dump` در PATH). هیچ شکست منطق دامنه در PG دیده نشد.
- `npm audit`: ۶ آسیب‌پذیری (۱ بالا: adm-zip؛ ۵ متوسط: minimatch و وابستگی‌ها).

## ۵. برنامهٔ اجرایی (مراحل مستقل)

1. اصلاحات فوری امنیتی/سازگاری (F1–F5) + تکرار آزمون روی هر دو دیتابیس.
2. **گارد تک پیشخوان**: مهاجرت ۰۴۵، ماژول تشخیص/پاسخ، اسکن یکپارچگی/آپلود/وابستگی، قرنطینه،
   مسدودسازی موقت IP، پیامک هشدار، API `/api/guard`، صفحهٔ مدیریت، آزمون‌ها.
3. SEO/اینماد/گوگل: گروه تنظیمات `seo`، پاک‌سازی امن کد اینماد، robots/sitemap کامل، تزریق فرانت‌اند.
4. بکاپ خارجی: مهاجرت ۰۴۶، آداپتور SFTP/FTP/Google Drive، انتقال خودکار، آزمون با سرور واقعی محلی.
5. مانیتورینگ: انقضای SSL، تازگی بکاپ، heartbeat زمان‌بندها.
6. نصب‌کنندهٔ سرور v2: رفع F2، journal/resume، قفل نصب، گزارش downloadable، بستهٔ اتصال اندروید، `--check-only`.
7. مستندات کامل + گزارش‌های تطبیق/دیتابیس/امنیت/آزمون + چک‌لیست نهایی.
8. اعتبارسنجی نهایی روی SQLite و PostgreSQL واقعی، build، contrast، selftest ویندوز؛ commit/push.

مواردی که به زیرساخت خارجی نیاز دارند و در این محیط قابل آزمون واقعی نیستند (صادقانه):
دامنه/DNS واقعی، Cloudflare، Let's Encrypt زنده، پیامک واقعی، درگاه بانکی زنده، Google Drive OAuth واقعی،
سرور VPS واقعی و دستگاه اندروید. این موارد در گزارش «باقی‌مانده‌ها» با دستور دقیق تحویل می‌شوند.
