# اجرای محلی و نصب آسان روی Windows

این نصب‌کننده برای **آزمون روی رایانهٔ شخصی** است؛ Windows Server/استقرار عمومی/دامنه و پرداخت واقعی را پیکربندی نمی‌کند. از SQLite محلی استفاده می‌کند و فقط به `127.0.0.1` گوش می‌دهد. برای Ubuntu/PostgreSQL عملیاتی از [نصب سرور](INSTALL.md) استفاده کنید.

## پیش‌نیاز

- Windows 10/11، PowerShell 5.1 یا جدیدتر
- Node.js 22.5 یا جدیدتر و npm؛ نسخه را با `node -v` و `npm -v` ببینید. اگر Node روی دستگاه نیست، نسخه LTS سازگار را از سایت رسمی Node.js نصب و پنجرهٔ PowerShell را دوباره باز کنید.
- اتصال اینترنت برای دریافت بسته‌های npm (نصب اول). هیچ پایگاه ابری، SMS یا درگاه بانکی لازم نیست.

## نصب با دوبار کلیک

1. نسخهٔ کد را از GitHub دریافت و ZIP را **در پوشه‌ای قابل نوشتن** مثل `C:\Pishkan` استخراج کنید. تا وقتی تغییرات در `main` ادغام نشده‌اند، برای نسخهٔ این PR شاخهٔ `arena/82749fce-pishkan` را انتخاب کنید؛ ZIP شاخه در صفحهٔ شاخه → **Code → Download ZIP** است.
2. `Install-Pishkan-Windows.cmd` را اجرا کنید. اگر Windows هشدار اجرای فایل اینترنتی داد، ابتدا ZIP را از منبع مورد اعتماد گرفته و `Properties → Unblock` را بررسی کنید.
3. نصب‌کننده نسخهٔ Node، port و فایل‌های ورودی را بررسی می‌کند، `npm ci` و `npm run build` را اجرا می‌کند، SQLite را می‌سازد، هشت migration را اعمال می‌کند، roleها و ۳ دسته/۳۰ خدمت کاتالوگ را می‌ریزد و **فقط اگر مدیر کل قبلی در DB نباشد** حساب اولیه را می‌سازد.
4. در انتهای نصب، نام کاربری و رمز تصادفی مدیر کل نشان داده و در `.data\initial-admin-credentials.txt` ذخیره می‌شود؛ همان را امن نگه دارید. رمز پیش‌فرض ثابتی در نصب‌کننده نیست. پس از ورود، رمز را تغییر دهید.
5. مرورگر روی `http://127.0.0.1:3000` باز می‌شود. گزینهٔ ورود **کارکنان و مدیران** را انتخاب کنید. مدیر کل تمام منوهای مجاز را می‌بیند. از «کارکنان و نقش‌ها» حساب کارمند/حسابدار بسازید و در پنجرهٔ ناشناس، سطح دسترسی هر نقش را جداگانه بیازمایید. برای آزمون مشتری، از «ثبت‌نام مشتری» استفاده کنید.

> اگر پورت 3000 اشغال است، PowerShell را در همان پوشه باز و این دستور را اجرا کنید: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1 -Port 3002`. برای نصب تازه، پورت را تنظیم می‌کند؛ روی نصب موجود فقط نشانی/پورت local را به‌روزرسانی می‌کند و DB/حساب‌ها را حفظ می‌کند. پورت فقط به loopback محلی متصل می‌شود.

## همهٔ پنل‌ها و دادهٔ نمونه

نصب عادی دادهٔ مشتری/پروندهٔ ساختگی وارد نمی‌کند؛ پنل‌ها خالی‌اند تا گردش واقعی را خودتان بسازید. کاتالوگ اولیه **نمونه و نیازمند تأیید تعرفه** است. از حساب مدیر، یک کارمند اجرایی، حسابدار و مشتری بسازید، سپس یک خدمت/درخواست آزمایشی ثبت و فایل نتیجه را به تأیید مدیریت بفرستید.

برای مرور سریع داشبورد با داده‌های ساختگی، از PowerShell اجرا کنید:

```powershell
.\Install-Pishkan-Windows.cmd -IncludeDemoData
```

این گزینه فقط در اولین پایگاه دادهٔ تازه، نام‌ها/پرونده‌های نمونه را می‌سازد؛ حساب‌های نمونه برای کارکنان `sara`, `reza`, `maryam`, `hesam` و رمز آن‌ها `Demo@12345` است. مشتریان نمونه نیز دادهٔ ساختگی‌اند و ورود آن‌ها ممکن است به روش پیامکی توسعه نیاز داشته باشد. **این کاربران، پرونده‌ها و تعرفه‌ها واقعی نیستند؛ هرگز در محیط عملیاتی یا کنار اطلاعات مشتری استفاده نکنید.** اجرای دوبارهٔ گزینه روی نصب موجود، seed نمونه را دوباره اجرا نمی‌کند و دادهٔ شما را حذف/جایگزین نمی‌کند.

## روشن/خاموش و محل داده‌ها

- `Start-Pishkan-Windows.cmd` — شروع سرور و بازکردن برنامه در مرورگر.
- `Stop-Pishkan-Windows.cmd` — توقف فقط پردازهٔ پشکان؛ پایگاه داده و فایل‌ها حذف نمی‌شوند.
- SQLite آزمون: `.data\pishkan-windows.sqlite`
- آپلودها: `.data\uploads`
- خروجی log: `.data\pishkan-windows-server.log` و `...-error.log`
- رمز اولیه: `.data\initial-admin-credentials.txt`
- پیکربندی محلی: `.env.windows.local` (حاوی کلید رمزگذاری؛ Git آن را ignore می‌کند).

نصب‌کنندهٔ تکراری DB/کاربران/فاکتور/تنظیمات را reset نمی‌کند. اگر DB موجود باشد اما فایل تنظیمات گم شده باشد، با پیام روشن متوقف می‌شود؛ یک کپی تازه از مخزن در پوشهٔ دیگری بگیرید و DB را پاک نکنید. تغییر کد از روی upgrade هم migration افزایشی اجرا می‌کند؛ این اسکریپت DB را پاک یا از نو ایجاد نمی‌کند.

## عیب‌یابی

- **Node پیدا نشد/نسخه کم است:** Node 22.5+ را نصب، همهٔ ترمینال‌ها را ببندید و دوباره باز کنید.
- **Execution Policy:** از فایل `.cmd` استفاده کنید؛ اگر PowerShell باز کردید، دستور مجاز همان اجرا است: `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1`.
- **npm ci ناموفق است:** اتصال registry.npmjs.org، پراکسی سازمانی و فضای دیسک را بررسی کنید؛ دادهٔ محلی پاک نمی‌شود.
- **پورت اشغال است:** `-Port 3002` بدهید. نصب‌کننده پردازه‌های برنامه‌های دیگر را متوقف نمی‌کند.
- **صفحه باز می‌شود ولی API سالم نیست:** `http://127.0.0.1:3000/api/health` را ببینید، سپس `Stop-Pishkan-Windows.cmd` و `Start-Pishkan-Windows.cmd` را اجرا کنید. logها در `.data` هستند.
- **پس از نصب قدیمی پنل/ورود کار نمی‌کند:** صفحه را `Ctrl+Shift+R` کنید؛ service worker ممکن است نسخهٔ قبلی فایل‌های وب را نگه داشته باشد.

این بستهٔ Windows از نظر اسکریپت در محیط Linux این مخزن build/typecheck شده، اما اجرای خود نصب‌کننده روی ماشین Windows واقعی در این نوبت در دسترس نبود. SQLite، داده‌ها، فایل‌ها و مدیر ساخته‌شده در یک مرورگر محلی/Windows واقعی باید پیش از هر استفادهٔ غیرآزمایشی بررسی شوند. برای چند کاربر، دسترسی شبکه‌ای، پشتیبان بیرونی یا دادهٔ حساس از این نصب توسعه استفاده نکنید.
