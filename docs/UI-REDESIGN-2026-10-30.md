نسخه: **۱٫۲٫۰** · دامنه: `apps/web` · شاخه: `arena/db057b54-pishkan`

این سند تصمیم‌های طراحی، توکن‌های رنگ، رفتار حالت تیره، تغییرهای کامپوننت‌ها و روش

## ۲. توکن‌ها

### لایهٔ معنایی

| توکن | نقش | روشن | تیره |
| --- | --- | --- | --- |
| `--canvas` | پس‌زمینهٔ صفحه | `#f2f6fc` | `#060c17` |
| `--surface` | کارت و پنل | `#ffffff` | `#0e1727` |
| `--surface-2` | نوار ابزار، سرستون جدول، ردیف یک‌درمیان | `#f7fafe` | `#121d31` |
| `--surface-3` | حالت hover، تراشهٔ خنثی | `#eef4fc` | `#17243b` |
| `--line` / `--line-strong` | حاشیه و جداکننده | `rgb(13 33 61 / .09)` | `rgb(255 255 255 / .09)` |
| `--shell` / `--shell-2` | سایدبار، فوتر عمومی، بنر خوش‌آمد | `#071a2e` → `#0b2b4a` | `#050b15` → `#0a1a2d` |
| `--shell-fg` / `--shell-muted` | متن روی پوستهٔ تیره | `#f2f7ff` / `#a3b8d2` | `#eef4ff` / `#8ea4c4` |
| `--primary` / `--primary-hover` | دکمهٔ اصلی | `#0b5fd0` / `#094eae` | `#2563eb` / `#3b82f6` |
| `--accent` | لینک، عنوان تأکیدی، آیکون فعال | `#0a4eae` | `#8cbcf7` |
| `--color-*-50…900` | پالت وضعیت (موفق/خطا/هشدار/اطلاع) | مقادیر استاندارد | تیره‌های تنظیم‌شده برای پس‌زمینهٔ تیره |

قاعدهٔ پالت وضعیت در هر دو حالت:

- `50/100/200` = پرکنندهٔ نرم (چیپ و پیام).
- `500/600` = رنگ توپر badges که متن سفید روی آن می‌آید (کنتراست ≥ ۴٫۵).
- `700/800/900` = رنگ متن روی پرکنندهٔ نرم.

پالت `navy-*` در حالت تیره معکوس می‌شود: `navy-900` «متن اصلی» است (در تیره نزدیک سفید) و
`navy-50` «نرم‌ترین پرکننده» (در تیره نزدیک پس‌زمینه). به همین دلیل کلاس‌های موجود
(`text-navy-900`, `border-navy-900/8`) بدون تغییر در هر دو حالت درست رفتار می‌کنند.

استثناها با توکن صریح حل شده‌اند: پوسته (`.app-sidebar`, فوتر, `WelcomePanel`) از `shell` استفاده
می‌کند، پردهٔ مودال از `--scrim`، و متن تأکیدی از `--accent` (به‌جای `text-brand-700` که در تیره
روی سطح تیره خوانا نبود).

## ۳. رفتار حالت تیره

| موضوع | پیاده‌سازی |
| --- | --- |
| کلید ذخیره | `pishkan.theme` در `localStorage` با مقادیر `light` \| `dark` \| `system`؛ انتخاب «سیستم» کلید را حذف می‌کند |
| جلوگیری از فلش | اسکریپت کوچک در `index.html` قبل از رندر، کلاس و `color-scheme` و `meta theme-color` را تنظیم می‌کند |
| هماهنگی با سیستم | `matchMedia('(prefers-color-scheme: dark)')` با گوش‌دادن به تغییر تنظیم دستگاه تا زمانی که حالت «سیستم» انتخاب شده باشد |
| چند تب | رویداد `storage` انتخاب را بین تب‌ها همگام می‌کند |
| نوار آدرس موبایل | رنگ `theme-color` در هر حالت به‌روز می‌شود (`#f2f6fc` / `#060c17`) |
| کنترل‌های بومی | `color-scheme` روی `<html>` تنظیم می‌شود تا تاریخ/انتخاب فایل و اسکرول‌بار درست دیده شوند |
| محل کنترل | آیکون سریع در هدر پنل، کلید کامل در پاپ‌اور حساب، و بخش «حالت نمایش» در پروفایل مشتری |

API عمومی: `useTheme()` → `{ mode, resolved, setMode, toggle }` و توابع `setThemeMode` / `toggleTheme`
برای استفادهٔ خارج از React. همهٔ آن‌ها بدون Provider هم کار می‌کنند (فروشگاه مستقل با
`useSyncExternalStore`).

## ۴. تغییرهای رابط

### پوسته (shell)

- سایدبار با گروه‌بندی موضوعی («فضای کار»، «حساب و ارتباط»، «عملیات روزانه»، «مدیریت»، «مالی و سامانه»)،
  نشانگر فعال کنار آیتم، کارت کاربر با کلید تم و دکمهٔ خروج.
- هدر شیشه‌ای (`.glass`) با مسیر راهنما (breadcrumb) بر اساس منوی فعال، جست‌وجوی خدمات، اعلان‌ها،
  کلید تم و پاپ‌اور حساب با انتخاب سه‌حالته.
- داک موبایل با شاخص فعال و ۴ آیتم اصلی + «همه بخش‌ها».
- پیوند «پرش به محتوای اصلی» برای صفحه‌کلید.

### کامپوننت‌ها (`components/ui.tsx`)

| کامپوننت | تغییر |
| --- | --- |
| `WelcomePanel` | **جدید** — بنر گرادیانی پوسته با badge، عنوان، توضیح و اکشن‌ها؛ در داشبورد مشتری و مدیریت |
| `StatCard` | آیکون در تراشهٔ رنگی، اثر `lift` در hover، رنگ‌های توکنی |
| `Card` / `SectionTitle` | سایه نرم، حاشیهٔ توکنی، پشتیبانی از `eyebrow` |
| `Badge` / `StatusBadge` | رنگ‌های نرم تیره‌آگاه |
| `Modal` | پردهٔ `--scrim`، سطح توکنی، دکمهٔ بستن `icon-btn` |
| `Tabs` | تبدیل به کنترل قطعه‌ای با `aria-pressed` |
| `Switch` | مسیر فعال با `--primary` |
| `EmptyState` / `ErrorState` | پس‌زمینه و متن توکنی، خوانایی در تیره |
| `ThemeToggle` / `ThemeSegmented` | **جدید** — کنترل آیکونی و سه‌حالته |

### صفحه‌ها

- **خانهٔ عمومی**: هیرو با گرادیان پوسته و تصویر ترکیب‌شده، جست‌وجوی شیشه‌ای، نوار دسته‌ها؛ هدر عمومی
  دارای کلید تم و فوتر با توکن‌های پوسته.
- **داشبورد مشتری**: بنر خوش‌آمد + اکشن سریع «درخواست جدید» و «مدارک من».
- **داشبورد مدیریت**: بنر با اکشن «گزارش‌های کامل» و «کارتابل تأیید».
- **پروفایل مشتری**: بخش «حالت نمایش».
- **همهٔ صفحات**: جایگزینی ۴۸ مورد `bg-white` با `bg-surface` و حذف رنگ‌های سخت‌کد (`#f6f8fa`, `#f4f8fe`, …).

## ۵. دسترس‌پذیری

- کنتراست: همهٔ جفت‌های متن/پس‌زمینهٔ اصلی در هر دو حالت از حد عبور می‌کنند (جدول §۶).
- `:focus-visible` یکسان با حلقهٔ ۲ پیکسلی رنگ اصلی.
- هدف لمسی حداقل ۴۴ پیکسل در موبایل برای دکمه‌ها و ورودی‌ها؛ داک پایین با `env(safe-area-inset-bottom)`.
- کنترل‌های تم `aria-pressed` و `role="group"` دارند؛ کلید سریع `aria-label` توصیفی دارد.
- احترام به `prefers-reduced-motion` (انیمیشن‌ها خاموش می‌شوند).

1. سوئیچ سریع، کلاس `.dark`، `data-theme` و ذخیره در `localStorage` را تغییر می‌دهد و محتوا سالم می‌ماند.

### محدودیت صادقانه

در این محیط، باینری Chromium موجود در `@sparticuz/chromium` به‌دلیل نبود کتابخانه‌های سیستمی
(`libnspr4`) اجرا نمی‌شود؛ بنابراین اسکرین‌شات خودکار و آزمون مرورگر واقعی انجام **نشده** است.
اعتبارسنجی انجام‌شده: توکن‌ها، کنتراست عددی، آزمون‌های jsdom، تایپ‌چک و بیلد تولیدی. پیشنهاد:
اجرای `npm run test:browser --workspace apps/web` روی CI با تصویر Playwright رسمی.

## ۷. افزودن استایل جدید

1. رنگ یا سطح جدید را در `:root` و `.dark` تعریف کنید؛ هرگز رنگ را داخل JSX سخت‌کد نکنید.
2. اگر نقش جدید است، آن را در `@theme inline` به یک نام معنایی وصل کنید (`--color-*`).
3. برای متن روی سطح تیره از `text-accent` یا `text-navy-*` استفاده کنید، نه `text-brand-700`.
4. برای پرکنندهٔ توپر با متن سفید از پلهٔ ۶۰۰ پالت وضعیت استفاده کنید.
5. پیش از کامیت: `npm run check:contrast && npm test --workspace apps/web`.
