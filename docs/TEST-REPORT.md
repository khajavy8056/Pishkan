## نتیجه اجرایی

کد قابل بیلد است و ۶۴ آزمون خودکار پاس شده‌اند. این نتیجه **گواه آماده‌بودن بدون شرط برای بهره‌برداری واقعی نیست**. استقرار Ubuntu، PostgreSQL واقعی، ارتباط پیامکی/بانکی و مرورگر و اندروید واقعی هنوز آزمون پذیرش لازم دارند.

محیط اجرا: Linux، Node `v22.22.3`، npm `10.9.8`، Vitest `4.1.12`، SQLite داخلی Node؛ رابط کاربری در jsdom.

## دستورات و نتایج واقعی

| بررسی | نتیجه |
| --- | --- |
| `npm ci` | موفق؛ نصب از lockfile |
| `npm run test --workspace apps/api` | ۵۰ تست در ۶ فایل، همگی موفق |
| `npm run test --workspace apps/web` | ۱۴ تست در ۲ فایل، همگی موفق |
| `npm run typecheck` | هر دو workspace بدون خطای تایپ |
| `npm run build` | بک‌اند و وب موفق |
| خروجی PWA | `sw.js` و فایل Workbox؛ ۲۱ ورودی precache، حدود ۷۳۲ KiB |
| `bash -n scripts/install.sh scripts/pishkan scripts/lib/common.sh` | موفق |
| `shellcheck -S warning scripts/install.sh scripts/pishkan scripts/lib/common.sh` | موفق؛ ShellCheck با بسته shellcheck-py در محیط مجزای موقت اجرا شد |
| `bash scripts/pishkan --help` | موفق؛ نمایش راهنمای CLI بدون تغییر سیستم |
| `npm audit` پس از اصلاح وابستگی‌ها | صفر آسیب‌پذیری گزارش‌شده؛ این نتیجه فقط snapshot پایگاه advisory زمان اجراست |

به‌روزرسانی Vitest از ۳ به ۴٫۱٫۱۲ برای رفع advisory ابزارهای آزمون و pin کردن Capacitor CLI به ۸٫۴٫۳ برای حذف زنجیره آسیب‌پذیر xcode/uuid انجام شد. ساخت APK با این نسخه هنوز اجرا نشده است. نصب اولیه مجدد با npm 10 هنگام حل peerهای جدید خطای داخلی Arborist داشت؛ تولید lockfile با npm 11٫۶٫۲ انجام و سپس `npm ci` با npm 10 با موفقیت تأیید شد.

پیام‌های `[sms:dev]` در خروجی تست از transport کنسول‌اند و **پیامک واقعی ارسال نشده است**. این transport مخصوص توسعه است و کد OTP آزمایشی را چاپ می‌کند؛ در تولید نباید استفاده شود.

## پوشش وب و هشدارها

۱۴ آزمون رندر صفحات عمومی و پنل‌ها با داده mock اجرا شده‌اند؛ این‌ها آزمون یکپارچه مرورگر با API واقعی نیستند. هشدار Experimental مربوط به SQLite در Node 22 مورد انتظار است. در اجرای پیشین تست صفحه ۴۰۴ هشدار React درباره `act` دیده شد؛ انتظار async برای رندر به تست اضافه شد. هشدار deprecation وابستگی توسعه `glob` هنگام نصب دیده می‌شود، حتی با audit صفر.

## انجام‌نشده‌ها و دروازه پذیرش تولید

- نصب و نصب مجدد idempotent روی Ubuntu تمیز؛ systemd، Nginx، TLS و دامنه واقعی.
- آزمون PostgreSQL واقعی، همزمانی پرداخت/ارجاع و تست بار.
- آزمون عملی ارتقا و rollback و restore کامل PostgreSQL همراه فایل‌ها و کلیدها روی سرور ثانویه. تست فعلی backup SQLite جایگزین این آزمون نیست.
- ارسال واقعی ملی پیامک با الگوی مصوب؛ نیازمند اعتبارنامه، تأیید صریح و شماره مقصد.
- ایجاد و verify تراکنش بانکی واقعی؛ تست فعلی از شبیه‌ساز استفاده می‌کند.
- مرورگر واقعی، نصب PWA، آفلاین، آزمون دسترس‌پذیری و اندازه‌های Windows/Android.
- ساخت و نصب APK/AAB، امضای انتشار و آزمون Android SDK؛ پروژه native هنوز تولید نشده است.
- ممیزی امنیتی مستقل، تست نفوذ، اعتبارسنجی همه تعرفه‌ها و شرایط از مرجع رسمی.
- جداسازی چنددفتره: پیاده‌سازی نشده؛ گزینه‌های تنظیماتی رزرو هستند. برای هر دفتر نصب مستقل لازم است.
