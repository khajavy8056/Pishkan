# پشکان — سامانه جامع اتوماسیون دفتر پیشخوان دولت

> **ممیزی جامع ۲۰۲۶-۱۰-۲۹:** retry امن ثبت درخواست و کنترل انتساب تکراری افزوده و آزمون‌ها دوباره اجرا شده‌اند. این نتیجه گواه آمادگی تولید نیست؛ آزمون PostgreSQL واقعی، پیامک/درگاه زنده، مرورگر واقعی و استقرار انجام نشده است. وضعیت دقیق شواهد و شکاف‌ها در [گزارش ممیزی آمادگی انتشار](docs/PRODUCTION-READINESS-AUDIT-2026-10-29.md) آمده است. گزارش‌های پیشین: [اصلاحات ۲۷ اکتبر](docs/CORRECTIONS-2026-10-27.md) و [ممیزی نیازمندی‌ها](docs/REQUIREMENTS-AUDIT.md).

سامانه‌ای یکپارچه برای مدیریت یک دفتر پیشخوان دولت: کاتالوگ خدمات با فرم‌های پویا، پرونده و گردش کار،
حسابداری عملیاتی، شیفت و حضور کارکنان، پیامک و پیام‌رسانی، دستیار هوشمند و مرکز تنظیمات.

- پنل مشتری (وب و اندروید/PWA)، پنل کارکنان و پنل مدیریت از **یک بک‌اند و یک پایگاه داده** تغذیه می‌شوند.
- تمام رابط کاربری **فارسی و راست‌به‌چپ** است و روی دسکتاپ ویندوز، تبلت و موبایل اندروید کار می‌کند.
- هر تغییری که مدیر در تنظیمات، خدمات، دسته‌ها یا هزینه‌ها بدهد، بلافاصله در همه کلاینت‌ها دیده می‌شود
  (هیچ فهرست ثابتی در کلاینت وجود ندارد).

> **وضعیت صداقت‌سنجی:** هزینه‌ها و شرایط پیش‌فرض خدمات **داده نمونه** هستند و با پرچم «نیازمند تأیید» علامت خورده‌اند.
> پیش از انتشار عمومی، تعرفه رسمی هر خدمت را از دستگاه صادرکننده تأیید و در پنل مدیریت وارد کنید.
> نصب روی سرور واقعی، خرید دامنه، ارسال پیامک واقعی و اتصال درگاه پرداخت در این محیط انجام نشده و
> در [docs/TEST-REPORT.md](docs/TEST-REPORT.md) با جزئیات گزارش شده است.

**افزوده ۲۰۲۶-۱۰-۲۷:** نقش‌های کارکنان/مدیران با یک درگاه ورود و مجوزهای مستقل، پنل حسابدار، کارتابل ارجاع مدیریت/مالی و تحویل امن فایل نتیجه به migration `008` اضافه شده‌اند. رابط آبی RTL در مرورگر Chromium رومیزی و viewport موبایل آزموده شد. آزمون‌ها و محدودیت‌های واقعی در [گزارش نقش و اتوماسیون](docs/ROLE-AUTOMATION-UI-2026-10-27.md) آمده است.

## ۳. نصب محلی روی Windows و اجرای همه پنل‌ها

راهنمای کامل و عیب‌یابی: [docs/WINDOWS-LOCAL.md](docs/WINDOWS-LOCAL.md). بستهٔ نصب سبک Windows شامل launcherهای CMD و نصب‌کنندهٔ PowerShell است (MSI امضاشده نیست). پس از نصب Node.js 22.22.2+، شاخهٔ جاری را دریافت کنید و روی `Install-Pishkan-Windows.cmd` دوبار کلیک کنید. نصب‌کننده با SQLite محلی، migrationها و کاتالوگ شروع می‌کند، رمز مدیرکل را تصادفی می‌سازد و پس از نصب نمایش می‌دهد؛ رمز ثابت منتشرشده ندارد.

```powershell
# در ریشهٔ پوشهٔ دریافت‌شده
.\Install-Pishkan-Windows.cmd
# یا برای پورت دیگر/داده‌های نمایشی اختیاری:
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1 -Port 3002 -IncludeDemoData
```

صفحه: `http://127.0.0.1:3000`؛ API سلامت: `http://127.0.0.1:3000/api/health`. دادهٔ نمونه پیش‌فرض خاموش است. نصب معمولی ۳ دسته و ۳۰ خدمت با هزینهٔ **نمونه** می‌سازد؛ پس از ورود مدیرکل از پنل کارکنان، حساب‌های کارمند/حسابدار را بسازید و مشتری را ثبت‌نام کنید. پورت فقط روی رایانهٔ محلی گوش می‌دهد.

برای اجرای دستی توسعه در سیستم‌های دیگر، Node.js 22.22.2+ لازم است. `.env.development.example` را کپی و یک رمز قوی مخصوص خود در `BOOTSTRAP_ADMIN_PASSWORD` بنویسید، سپس `npm ci`, `npm run build` و `npm run dev` اجرا کنید. هیچ رمز پیش‌فرضی برای مدیر ساخته نمی‌شود مگر آن را خودتان تنظیم کنید. نصب Windows، مسیرهای نگهداری داده، اختیارات و محدودیت‌ها: [راهنمای Windows](docs/WINDOWS-LOCAL.md).

## ۴. نصب روی سرور (Ubuntu 22.04/24.04)

> دستورها به commit تغییرناپذیر `c92c4525332213f82d80a005291d2782485fdcd6` روی شاخه ممیزی‌شده pin شده‌اند، نه `main`. این commit از GitHub دریافت و SHA آن تأیید شد؛ نصب سرور واقعی/تولیدی با آن انجام نشده و PR هنوز باز است.

```bash
PISHKAN_COMMIT='c92c4525332213f82d80a005291d2782485fdcd6'
curl -fsSL "https://raw.githubusercontent.com/khajavy8056/Pishkan/${PISHKAN_COMMIT}/scripts/install.sh" \
  | sudo env PISHKAN_COMMIT="${PISHKAN_COMMIT}" bash
```

با دامنه و ایمیل (برای HTTPS خودکار):

```bash
PISHKAN_COMMIT='c92c4525332213f82d80a005291d2782485fdcd6'
curl -fsSL "https://raw.githubusercontent.com/khajavy8056/Pishkan/${PISHKAN_COMMIT}/scripts/install.sh" \
  | sudo env PISHKAN_COMMIT="${PISHKAN_COMMIT}" DOMAIN=pishkan.example.ir EMAIL=admin@example.ir bash
```

نصب‌کننده پیش‌نیازها را بررسی می‌کند و در صورت کمبود منابع با پیام روشن متوقف می‌شود،
PostgreSQL و Nginx و Node.js 22.22.2+ را نصب می‌کند، کلیدهای تصادفی می‌سازد، مهاجرت‌ها را اجرا می‌کند و
رمز اولیه مدیر کل را **یک بار** نمایش می‌دهد. جزئیات: [docs/INSTALL.md](docs/INSTALL.md)

## ۵. مدیریت روزانه

```bash
pishkan status        # وضعیت سرویس، نسخه و سلامت
pishkan logs -f       # لاگ زنده
pishkan update        # به‌روزرسانی امن (پشتیبان‌گیری + بازگشت خودکار در صورت خطا)
pishkan rollback      # بازگشت به نسخه قبلی
pishkan backup        # پشتیبان‌گیری از پایگاه داده و مدارک
pishkan restore FILE  # بازیابی با تأیید صریح
pishkan doctor        # بررسی کامل نصب
```

## ۷. وضعیت پایگاه داده

- **تولید:** PostgreSQL ۱۵/۱۶ (نصب‌کننده خودکار راه‌اندازی می‌کند).
- **توسعه و CI:** SQLite داخلی Node (`node:sqlite`) برای اجرای سریع آزمون‌ها بدون سرویس خارجی.
- مهاجرت‌ها افزودنی و نسخه‌بندی‌شده‌اند؛ هیچ مهاجرتی جدول مشتری، فاکتور، تراکنش یا تنظیمات را حذف نمی‌کند.

## ۸. کارهای باقی‌مانده (صادقانه)

- ارسال پیامک واقعی و اتصال درگاه پرداخت باید با اعتبارنامه‌های مالک در سرور واقعی آزموده شود.
- دامنه خریداری/متصل نشده است؛ دستورهای دقیق در `docs/DOMAIN-CLOUDFLARE.md` آمده است.
- جداسازی چنددفتره هنوز پیاده‌سازی نشده؛ برای هر دفتر نصب و پایگاه داده مستقل لازم است.
- APK اندروید در این محیط ساخته نشده (نیازمند Android SDK)؛ مراحل ساخت مستند شده است.
- صفحه‌ها با تست رندر (jsdom) و بررسی تایپ و بیلد تأیید شده‌اند، اما آزمون End-to-End مرورگر واقعی انجام نشده است.
