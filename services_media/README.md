# تصاویر خدمت‌ها — جای بارگذاری تصویر

این پوشه محل گذاشتن تصاویر خدمت‌هاست. دو زیرپوشه دارد که کارشان متفاوت است:

```
services_media/
├── icons/       ← تصویر مربعی/گرد کوچک خدمت (همان که در فهرست خدمات دیده می‌شود)
└── backdrops/   ← تصویر بزرگ که در بالای صفحهٔ خود خدمت می‌نشیند
```

## نام فایل‌ها

نام هر فایل باید **دقیقاً** `اسلاگ خدمت` باشد و پسوندش `.webp` (یا `.png`).
اسلاگ همان بخش انگلیسی آدرس خدمت است.

| خدمت | نام فایل |
|---|---|
| دریافت قبض تأمین اجتماعی | `tamin-pensioner-payslip.webp` |
| تعویض پلاک خودرو | `plate-replacement-appointment.webp` |
| ثبت شرکت سهامی خاص | `register-jsc.webp` |
| دریافت کروکی تصادف | `accident-sketch.webp` |

فهرست کامل اسلاگ‌ها داخل `apps/mobile/assets/service_art/` است: هر فایل `.webp`
که آن‌جا موجود است، یک خدمت است و اسمش همان اسلاگ است. (`large/` نسخهٔ بزرگ همان
تصاویر است و برای بارگذاری شما لازم نیست.)

## مشخصات پیشنهادی

| | icons/ | backdrops/ |
|---|---|---|
| اندازه | ۲۵۶ × ۲۵۶ | ۱۰۸۰ × ۷۲۰ |
| پس‌زمینه | شفاف یا خیلی روشن | پرکننده (تمام کادر) |
| حجم | زیر ۶۰ کیلوبایت | زیر ۲۵۰ کیلوبایت |
| قالب | WebP ترجیحاً، PNG هم می‌شود | WebP ترجیحاً |

پسوند `.svg` استفاده نشود — اپ فلاتر آن را نمایش نمی‌دهد.

## بعد از بارگذاری

فقط فایل را در پوشهٔ درست بگذارید و بگویید؛ اسم‌گذاری درست باشد کافی است.
اگر تصویری نباشد، اپ تصویر فعلی را نشان می‌دهد و چیزی خراب نمی‌شود — یعنی
می‌توانید کم‌کم و فقط برای خدمت‌هایی که تصویر آماده دارید اضافه کنید.

> در حال حاضر تصاویر موجود در `apps/mobile/assets/service_art/` نمایش داده
> می‌شوند. این پوشه برای تصاویر شما آماده شده و جایگزین آن‌ها می‌شود.
